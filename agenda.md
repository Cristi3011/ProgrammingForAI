# Lecture agenda — Week 1 (2h)

The first week has no Lightning Demos (there's no previous challenge to present) — those start in Week 2.

| Time | Activity |
|---:|---|
| 15 min | Course intro: the challenge-based format, what "problem-first" means, brief rundown of grading (40% lab + 40% project + 20% final component from the syllabus) |
| 15 min | InstaKill presentation: the project brief, the 5 mandatory AI/engineering requirements, milestone timeline |
| 45 min | Theory concept: Python for AI — what "programming for AI" means differently from general programming (data, models, evaluation, reproducibility) |
| 30 min | Live coding: run a pretrained sentiment model (HF text-classification) on a few IMDb reviews, show live what a "disagreement" between model and label looks like |
| 15 min | Reveal challenge W1 (`AI Model Detective`) + explain acceptance criteria + Q&A |

## Notes for the instructor

- Don't solve the full challenge in live coding — show only the mechanics (how to load the model, how to inspect an output), not the solution (students must find the 5 disagreements themselves).
- Remind students of the compute policy: CPU is a guaranteed fallback, but if someone has a GPU available (local or Colab), they can use it — it's not forbidden.
- Announce the lightning-talk bonus rule from week one (+0.25/presentation, max +1.00), effective from W2.
